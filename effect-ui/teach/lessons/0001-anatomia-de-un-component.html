Cuatro piezas, un archivo

El artículo, sección «Anatomy of a Component», dice que cada Component es un programa Elm: Model, Messages, init, update y view. El padre no guarda ese estado ni reenvía sus Messages.

  • El Model es lo que update cambia: borrador, filtro, lista, fase.
  • Un Message nombra un hecho. SubmittedTodo no dice «inserta»; dice que el formulario se envió.
  • update es puro. ClickedFilter solo cambia filter. Borrar sí pide un Command, en la lección 2.
  • La view pinta. El botón construye ClickedToggle; no muta el arreglo.

Guía del mismo snapshot, «Naming»: ai-docs/src/10_ui/index.md. Verbo en pasado, la causa primero. 

ClickedFilter: ($, { filter }) => $.evolve({ filter })

Está en src/TodoList.ts. $.evolve cambia el campo que nombras y deja el resto. El filtro no es una lista nueva: la view filtra al pintar.
