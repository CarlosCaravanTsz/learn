Hazlo en el piloto

Agrega «borrar hechas» a TodoList.ts y una Story en TodoList.story.test.ts. No mires la solución hasta que pnpm test pase, o hasta que te atores de verdad.

  1. Tag nuevo en TodoListMessage. Escríbelo aquí, igual que los otros Clicked….
  2. En update: si phase no es "ready", regresa el Model. Quédate con las tareas donde completed es false. Si no cambió la cantidad, regresa el Model. Si cambió, $.evolve y SaveTodos.make.
  3. En la Story: carga vacía, agrega «Leche», complétala, resuelve cada SaveTodos, manda el Message nuevo, y espera la lista vacía más un SaveTodos con todos: [].

Solución, cuando ya lo intentaste

En TodoListMessage:

ClickedClearCompleted: {}

En update:

ClickedClearCompleted: ($) => {
  if ($.model.phase !== "ready") return $.model
  const todos = $.model.todos.filter((todo) => !todo.completed)
  if (todos.length === $.model.todos.length) return $.model
  return $.evolve({ todos, notice: null }).run(SaveTodos.make({ todos }))
}

Al final de la Story que ya completa «Leche» y resuelve ese guardado:

story.send(TodoListMessage.ClickedClearCompleted())
assert.deepStrictEqual(story.model.todos, [])
const cleared = SaveTodos.make({ todos: [] })
story.expectExact(cleared).resolve(cleared, saved)
