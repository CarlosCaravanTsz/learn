Cargar datos con servicios y Schema

Un servicio decide de dónde sale el dato. Un Schema comprueba si el dato que llegó cumple el contrato.

El contrato de la operación

Effect.Effect<Profile, RequestError | Schema.SchemaError, ProfileSource>

En loadProfile, yield* ProfileSource pide al runtime la implementación asociada a esa clave de servicio. source.get(id) entrega un unknown. Schema.decodeUnknownEffect(Profile)(raw) examina el valor en tiempo de ejecución. Un objeto con name: 42 produce un SchemaError. Si la promesa rechaza, tryPromise lo transforma en RequestError y la validación queda sin ejecutar. Services · Schema

Dónde se elige la implementación

const runnable = loadProfile(id).pipe(Effect.provide(demoSource))
await Effect.runPromise(runnable)

Layer.succeed registra una implementación ya construida. Effect.provide conecta esa capa al programa y satisface ProfileSource, por lo que aquí el requisito R pasa a never. Puedes usar otra capa para consumir HTTP sin modificar la validación. En una implementación con fetch, comprueba response.ok y pasa el AbortSignal que tryPromise entrega al callback si quieres que la interrupción llegue a la petición. Layers · Creating Effects

El runtime ejecuta cada programa en una fiber, una unidad de ejecución que Effect puede coordinar e interrumpir. Si una operación necesita abrir un recurso, acquireRelease registra su cierre y scoped delimita su vida útil. Para fallos transitorios, retry(Schedule.recurs(2)) permite hasta dos reintentos tras el intento inicial. Aplica esa política en el punto que pueda fallar de forma transitoria, como el acceso a la red. Runtime · Scope · Retrying

Práctica

En 02-services.ts, cambia solo la respuesta de "invalid" a { id, name: "Lin" }. Predice qué aserción de run-services.ts falla. Actualízala y vuelve a correr npm run services. Después retira temporalmente Effect.provide(demoSource) del runner y mira npm run check.

Comprobar el resultado

invalid produce Lin y la aserción todavía espera SchemaError. Al quitar la capa, TypeScript señala que runPromise exige un Effect con R = never y que todavía falta ProfileSource. Restaura la capa al terminar.

Si el error del compilador te resulta difícil de leer, trae el mensaje y revisamos de dónde viene cada parámetro.
