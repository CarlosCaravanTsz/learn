Construir y ejecutar un Effect

Un valor de tipo Effect describe trabajo. El runtime de Effect interpreta esa descripción al ejecutarla.

Cuándo empieza el trabajo

const program = Effect.sync(() => console.log("Dentro"))
console.log("Fuera")
await Effect.runPromise(program)

La salida es Fuera y luego Dentro. sync guarda la función. runPromise pone el programa en marcha y devuelve una promesa. Con fetch(url), la petición empieza al invocar fetch. Si lo adaptas con Effect.tryPromise({ try: () => fetch(url), catch: … }), la llamada queda dentro de una función diferida. Pasar un valor a Effect.succeed evalúa primero el argumento según las reglas normales de JavaScript. Creating Effects

Qué describe el tipo

En Effect.Effect<number, InvalidQuantity, never>, number es el resultado exitoso, InvalidQuantity es el fallo esperado y el último never dice que todos los requisitos están satisfechos. Un segundo never indica que el canal de fallos esperados está vacío. Siguen siendo posibles defectos inesperados e interrupciones. The Effect Type · Running Effects

Qué hace yield*

const program = Effect.gen(function* () {
  const quantity = yield* parseQuantity(input)
  yield* Effect.sync(() => console.log(quantity))
  return quantity * 25
})

Cuando se ejecuta el programa, el generador cede el primer Effect al runtime. Si tiene éxito, el runtime reanuda el generador con el número. Si falla, propaga el fallo y el log queda sin ejecutar. map sirve cuando el paso siguiente devuelve un valor ordinario. Usa flatMap cuando devuelve otro Effect que también hay que ejecutar.
