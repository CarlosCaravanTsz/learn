Referencia de Effect y Elm

Effect 4

Effect<A, E, R>
Éxito, fallo esperado y servicios requeridos.
sync · try · tryPromise
Difiere una función síncrona, adapta una función que podría lanzar, o adapta una promesa que podría rechazar.
map · flatMap · gen
Transforma un éxito, encadena otra operación o compone varios pasos con yield*.
Context.Service · Layer · provide
Declara una dependencia, define cómo obtener su implementación y conéctala al programa.
runPromise · runPromiseExit
El primero devuelve una promesa que puede rechazar. El segundo devuelve una promesa con un Exit que conserva el resultado o la causa del fallo.

Arquitectura Elm

init → Model inicial y Commands iniciales
update(Model, Message) → Model nuevo y Commands
view(Model) → interfaz
Command / Subscription / evento de interfaz → Message

Para depurar una transición, anota el Model previo, el Message y el Model esperado. Puedes llamar a update directamente y también comprobar los Commands que devuelve.
