Mapa React → Foldkit

Traduce lo que ya sabes de React al vocabulario de Foldkit. Punto de partida, no equivalencia uno a uno. Fuente: Coming from React.

React organiza el comportamiento alrededor de componentes y Hooks. Foldkit lo organiza alrededor de un Model, Messages, update y una view. El primer counter de Foldkit es más largo porque nombra la máquina de estados antes de que la app la necesite — y ese costo se paga una vez.

El mismo counter, lado a lado

React: estado y efecto conviven en el componente

// el estado vive en el hook; el efecto vive en el handler
const [count, setCount] = useState(0)

const handleClickIncrement = () => {
  setCount(count => count + 1)
}

Foldkit: cada pieza tiene su sitio nombrado

// MODEL: estado de TODA la app, con Schema
const Model = Schema.Struct({ count: Schema.Number })

// MESSAGE: un hecho ocurrido, no una orden
const Message = defineMessageUnion({ ClickedIncrement: {} })

// UPDATE: la única función que cambia el Model
const update = (model, message) =>
  Message.match(message, {
    ClickedIncrement: () => ({
      model: modifyFields(model, { count: c => c + 1 }),
    }),
  })

// VIEW: pura; el handler construye un Message
h.button([h.OnClick(Message.ClickedIncrement())], ['Increment'])

La diferencia que más se nota

En React, el problema de leer valores actuales desde un efecto exige herramientas como useEffectEvent y decisiones sobre arrays de dependencias: el intervalo captura closures del render. En Foldkit ese problema no existe: la Subscription solo se activa por una condición del Model, emite un Message (Ticked), y update lee el Model actual cuando ese Message llega. No hay closure que envejezca ni segunda mecánica para "leer lo último".

Consecuencia práctica para tests: no se necesita esperar un timer real — Ticked es un valor que el test despacha directamente contra update.

Si vienes de Redux

Model ≈ store, Message ≈ action, update ≈ reducer. Dos diferencias: update también devuelve Commands, y la unión de Messages se matching exhaustivo (el compilador te avisa si falta un caso).
