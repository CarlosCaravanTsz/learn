Glosario de Foldkit

El vocabulario mínimo para leer cualquier pieza de una app Foldkit. Fuente: la documentación oficial de arquitectura.

Cada término se usa con este significado exacto en todas las lecciones y ejercicios. Si un término no está aquí, no lo damos por sabido.

El núcleo del loop

TérminoDefinición
Model La única estructura de datos que guarda todo el estado de la aplicación. Se define con Schema.Struct de Effect y es inmutable: nunca se muta, se reemplaza.
Message Un hecho sobre algo que ocurrió: un clic, una tecla, una respuesta HTTP. Se declara con defineMessageUnion. Nombres past-tense verb-first: ClickedIncrement, SucceededFetchWeather, CompletedDelayReset.
update Función pura que recibe el Model actual y un Message, y devuelve el siguiente Model más una lista (posiblemente vacía) de Commands. Es el único lugar donde cambia el estado.
view Función pura que renderiza el Model como HTML (Document = { title, body }). Sus handlers construyen Messages; jamás ejecutan efectos ni cambian estado.
Runtime El motor de Foldkit: ejecuta Commands, corre Subscriptions, gestiona Mounts y recursos, y redirige cada Message resultante de vuelta a update. Se arranca en entry.ts con Runtime.makeApplication + Runtime.run, separado de las definiciones puras de main.ts.
Command Descripción (dato) de un efecto one-shot: petición HTTP, delay, focus, escritura en localStorage. Se define con Command.define('Nombre', { messages, execute, args?, interrupt? }). El runtime lo ejecuta y devuelve el resultado como uno de sus Messages declarados.

Fuentes de Messages y recursos

TérminoDefinición
Mount Trabajo imperativo atado al ciclo de vida de un elemento del DOM real (portal, observer, librería third-party). Emite un Message al acquire y hace cleanup cuando el elemento se desmonta.
Subscription Stream con scope, activo solo mientras una porción del Model mantiene un valor. Convierte fuentes externas (timers, WebSockets, cambios de tema) en Messages. El runtime la arranca y para según esa condición.
Resource Dependencia de duración-app (RpcClient, cliente de analytics, worker) compartida con Commands, Subscriptions y Flags. No produce Messages: es una dependencia, no una fuente.
ManagedResource Handle con estado (WebSocket, cámara, pool de workers) vivo mientras una porción del Model mantiene un valor. El runtime lo adquiere y libera; los Commands lo usan con tipo y reciben ResourceNotAvailable si no está.
Submodel Un Model + Message + update + view autónomos que un programa padre embebe y delega. Comunica hechos de alto nivel al padre mediante outMessage. Todos los componentes con estado de Foldkit UI son Submodels.

Piezas de Effect que Foldkit usa

TérminoDefinición
Effect Valor que describe un cómputo con efectos (async, fallo, dependencias) sin ejecutarlo. Es el tipo con el que se define Command.execute. En Foldkit, toda la app es un Effect.
Schema Definición de datos con validación en runtime y tipo TypeScript derivado. El Model completo y los payloads de Messages se definen con Schema: type Model = typeof Model.Type.
Stream Secuencia de valores en el tiempo (de Effect). Materia prima de Subscriptions y de Mount.defineStream.
Layer Constructores de dependencias/servicios de Effect (ej. Http.layer provee el HttpClient). Se "provide" a los Effects que las necesitan.
Interrupción Corte explícito de un Command en vuelo: interrupt: true (una sola instancia por nombre) o interrupt: { keyFields, toKey } (por clave derivada de args). El Interrupt devuelve Interrupted o NotFound.

Helpers de Foldkit que verás en cada ejemplo

HelperPara qué sirve
defineMessageUnion Declara la unión de Messages y sus constructores invocables: Message.ClickedIncrement(). También da Message.match con matching exhaustivo.
Message.match Maneja cada variante del union; TypeScript exige cubrirlas todas. Es el cuerpo típico de update.
modifyFields Actualización inmutable del Model: modifyFields(model, { count: c => c + 1 }) devuelve un nuevo Model; el original queda intacto.
Update.Return<Model, Message> Tipo del retorno de update: { model, commands? }.
Command.define Define un Command con nombre, Messages de resultado y el Effect execute.
