Comandos

  • npm run dev levanta el ejemplo con recursos emulados.
  • npm run check comprueba contratos de TypeScript.
  • npx alchemy plan --stage lab-cloud calcula el cambio para ese entorno.
  • npx alchemy deploy --stage lab-cloud pide confirmación y aplica el plan.
  • npx alchemy destroy --stage lab-cloud propone eliminar los recursos de ese entorno.
