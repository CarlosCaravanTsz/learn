# Recursos oficiales de Alchemy

## Documentación

- [Getting Started](https://alchemy.run/getting-started/) documenta la instalación y el primer stack.
- [Stacks](https://alchemy.run/infrastructure-as-code/stack/) explica cómo nombrar un grupo de recursos y usarlo en distintos entornos.
- [Resource Lifecycle](https://alchemy.run/infrastructure-as-code/resource-lifecycle/) describe las decisiones del plan y las operaciones del proveedor.
- [State Store](https://alchemy.run/state-store/) explica qué guarda Alchemy entre ejecuciones.
- [Renaming Resources](https://alchemy.run/infrastructure-as-code/renaming/) explica cómo conservar la identidad al cambiar un identificador lógico.
- [Migrating from v1](https://alchemy.run/migrating-from-v1/) muestra la API v2 y los manejadores HTTP con `async fetch`.
- [Cloudflare Local Development](https://alchemy.run/cloudflare/local-development/) describe el arranque local, la emulación y los recursos remotos.
- [React con Vite](https://alchemy.run/cloudflare/frontend/vite-spa/) desarrolla el siguiente paso con una aplicación de React.
- [Alchemy v2 beta.87](https://alchemy.run/blog/2026-11-12-beta-87/) documenta la versión usada en el ejemplo.

## Comunidad

- [Repositorio oficial de Alchemy](https://github.com/alchemy-run/alchemy) publica el código, registra problemas y enlaza la comunidad.
