# Misión de aprendizaje de Alchemy

## Por qué

Aprovechar la experiencia con React y TypeScript para describir, probar y entender los servicios que necesita una aplicación web.

## Resultados

- Seguir el recorrido de una solicitud HTTP desde el Worker hasta el almacenamiento.
- Explicar qué cambia al editar un identificador lógico, una propiedad o el cuerpo de una solicitud.
- Leer un plan y reconocer cuándo un cambio puede eliminar datos.

## Punto de partida

Conocimientos de React y TypeScript. Primer contacto con infraestructura como código. La práctica inicial usa Cloudflare en local.
