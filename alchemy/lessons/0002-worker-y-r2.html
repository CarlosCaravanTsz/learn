Un Worker que guarda una nota

Un Worker recibe una petición y usa el binding env.Notes para leer o escribir en R2. Vas a comprobar ambas operaciones con la versión local de Cloudflare.

Construcción y ejecución

En alchemy.run.ts, Effect.gen arma un programa que Alchemy evalúa. yield* Notes incluye el recurso y te da acceso a atributos como bucketName. La secuencia del generador se parece a la de await, pero cada Effect es una descripción del trabajo que el motor interpreta en su contexto. Los atributos de salida pueden depender del resultado del plan aplicado.

En worker.ts, fetch se ejecuta por cada solicitud. El import de WorkerEnv aporta tipos y desaparece del código JavaScript. Cloudflare entrega el objeto env al Worker cuando ejecuta el manejador.

const Notes = Cloudflare.R2.Bucket("Notes");
const Api = Cloudflare.Worker("Api", {
  main: "./worker.ts",
  env: { Notes },
});

export type WorkerEnv = Cloudflare.InferEnv<typeof Api>;

La clave Notes de env determina el acceso env.Notes en el manejador. La cadena "Notes" en Bucket identifica el recurso para Alchemy. El ejercicio de la tercera lección cambia esta cadena y deja el binding igual.

Corre el ejemplo

cd alchemy/examples
npm ci
npm run check
npm run dev

Desde otra terminal, usa la URL que imprima Alchemy. En los comandos se usa http://localhost:1337 como ejemplo.

base=http://localhost:1337
curl -i "$base/health"
curl -i "$base/note"
curl -i -X PUT --data 'Hola desde TypeScript' "$base/note"
curl -i "$base/note"

En un entorno nuevo debes ver 200, 404, 204 y 200. La última respuesta contiene el texto que enviaste. Si ya escribiste una nota, la primera lectura devuelve esa nota. Detén el proceso con Ctrl+C al terminar.

Practica

Escribe otra nota y predice cuántos objetos habrá

Sigue habiendo un objeto con clave note.txt. put reemplaza su contenido. Ejecuta otro PUT y luego GET para comprobarlo.

Agrega DELETE /note y comprueba que la lectura vuelva a dar 404

Agrega una rama para DELETE que llame a await env.Notes.delete("note.txt") y devuelva 204. Añade DELETE al encabezado Allow. Guarda, ejecuta npm run check y prueba con curl -i -X DELETE "$base/note" seguido de otro GET.

El ejemplo está diseñado para el laboratorio local. Publicar el manejador tal cual daría a quien conozca la URL acceso de lectura y escritura a la nota.
